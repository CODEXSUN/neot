# Discovery Questions

Ask the smallest useful set.

1. What result must this project produce?
2. Who uses the process and who owns it?
3. What event starts the process?
4. What steps happen today?
5. Which systems and data sources are involved?
6. Where do delays, errors, or repeated work occur?
7. Which rules and approvals control the work?
8. Which exceptions need human judgment?
9. What must never happen?
10. How will the business measure success?

For a future project, record the outcome, actors, current process, future process, constraints,
data, integrations, risks, metrics, and next decision.
