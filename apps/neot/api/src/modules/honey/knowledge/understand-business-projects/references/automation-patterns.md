# Automation Patterns

- Intake: collect complete data with validation.
- Routing: assign work by rules, capacity, or responsibility.
- Notification: inform a person after a defined event.
- Approval: require an authorized decision before a sensitive step.
- Synchronization: copy approved data between systems with conflict handling.
- Scheduling: start work at a defined time or interval.
- Reconciliation: compare records and report differences.
- Escalation: raise overdue or high-risk work to an owner.
- Document generation: create a reviewed document from approved data.
- Reporting: calculate agreed metrics from a known source.

For each pattern, define the trigger, inputs, rule, owner, action, output, exception, audit record,
and success metric. Keep a human checkpoint for money, legal commitments, customer communication,
production changes, and destructive actions.
