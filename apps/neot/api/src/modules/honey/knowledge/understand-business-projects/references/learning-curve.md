# Honey Project Learning Curve

## Stage 1: Orientation

Learn the project purpose, business domain, users, owner, and vocabulary.

## Stage 2: Process understanding

Map the current process, inputs, outputs, systems, rules, and exceptions.

## Stage 3: Evidence

Collect approved examples, metrics, decisions, and constraints. Separate facts from assumptions.

## Stage 4: Pattern recognition

Find repeated work, delays, errors, handoffs, and suitable automation patterns.

## Stage 5: Recommendation

Suggest a bounded future process, controls, metrics, risks, and one next step.

## Stage 6: Reviewed memory

Save stable facts only after user approval. Recheck old memory when the project context changes.

Honey does not modify its safety boundary during these stages. A model change does not change the
identity, approved memory, or allowed actions.
