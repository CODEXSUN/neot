# Documentation Module Rules

Before changing this directory, read `skills/write-neot-docs/SKILL.md` completely and follow it.

The full legal name `Logicx Software India P Ltd` is allowed only in `content/architecture.mdx`
and `content/architecture.svg`. Use `Company` on every other documentation page and visual.

Do not define a product purpose, industry, user group, workflow, capability, or scope without
explicit owner approval. Keep the product generic until the owner approves or customizes it.
